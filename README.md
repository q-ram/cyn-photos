# 청년회의 밤 사진 정리 (PWA)

교회(서울 송파구 풍납동)에서 **수·토·일**에 찍은 사진만 골라 날짜별로 묶고, 날짜 폴더 ZIP으로 저장하는 웹앱입니다.
사진을 고르고 거르고 모으는 일은 모두 폰 브라우저 안에서만 합니다. 서버나 외부 저장소는 없습니다. 사진은 사용자가 **보내기**로 고른 곳(카톡·메일 등)으로만 나갑니다.

## 파일 구성
| 파일 | 하는 일 |
|---|---|
| `index.html`, `css/style.css` | 화면 |
| `js/app.js` | 불러오기·미리보기·목록·크게 보기·저장 |
| `js/core.js` | 날짜/요일 계산, 풍납동 경계 판정, 분류, 파일 이름, ZIP 만들기 (화면과 분리) |
| `js/pungnap.js` | 풍납1동·풍납2동 경계 (vuski/admdongkor `ver20261001`) |
| `js/vendor/exifr.full.umd.js` | EXIF 읽기 (exifr 7.1.3, MIT) |
| `js/vendor/heic2any.min.js` | 브라우저가 못 여는 HEIC를 보기용으로 바꿈 (heic2any 0.0.4, MIT, 필요할 때만 불러옴) |
| `manifest.webmanifest`, `sw.js`, `icons/` | 홈 화면 추가·오프라인 |
| `js/collection.js` | 모음함 저장(IndexedDB), 받은 ZIP 읽기 |

## 동작 규칙
- **날짜·요일**: EXIF `DateTimeOriginal` 문자열을 그대로 씁니다(시간대 변환 없음). 없으면 `CreateDate` → `DateTime` 순서로 찾습니다.
- **장소**: GPS 좌표가 풍납1동·풍납2동 경계 안이거나 경계에서 여유 거리(기본 50m) 안이면 풍납동입니다.
- **분류 순서**: 날짜 없음 → 기간 밖 → 다른 요일 → 위치 없음 → 풍납동 / 다른 동네
- **고른 상태**: 풍납동 사진은 기본으로 골라져 있고, 위치 없음·다른 동네 사진은 사용자가 ＋로 넣습니다.
- **저장 이름**: `2026-03-18_수/2026-03-18_수_1930_이름_001.jpg` (날짜마다 촬영 시간 순서로 번호, 확장자는 원본 그대로)
- **ZIP**: 압축하지 않고 원본 파일을 그대로 담습니다. 사진을 메모리에 쌓지 않아 수백 장도 됩니다. ZIP 하나가 4GB를 넘으면 날짜별로 저장하라고 알려 줍니다.

## 모음함과 보내기 (서버 없음)
1. **임원**: 사진을 걸러 **모음함에 담기**를 누른 뒤, 모음함에서 **보내기 · 저장 → 보내기**를 누르고 카톡·메일을 고릅니다. 사진은 날짜 폴더로 묶인 ZIP으로 나갑니다.
2. **영상 만드는 사람**: 받은 ZIP을 폰(또는 PC 브라우저)에 저장한 뒤 모음함의 **받은 파일 불러오기**로 넣습니다. 여러 사람 ZIP을 한 번에 골라도 됩니다.
   모든 임원의 사진이 날짜별로 합쳐지고, 사람별로 걸러 볼 수 있습니다.
3. 다 모으면 **저장**으로 ZIP을 받아 영상 작업에 씁니다.

- 모음함은 폰 브라우저 저장소(IndexedDB)에 원본 그대로 저장됩니다. 앱이나 브라우저 데이터를 지우면 사라지므로, 다 모은 뒤에는 ZIP으로 저장해 두세요.
- 같은 사진(크기와 내용 CRC가 같은 사진)은 몇 번을 받아도 한 장만 남습니다.
- 보낼 때 묶는 방법은 넷 중에 고릅니다: 한 파일로 / 날짜별로 / 메일용(20MB씩) / 카톡용(200MB씩).
- 받은 파일은 이 앱이 만든 ZIP(압축 안 함)과 일반 압축 ZIP을 모두 읽습니다.
  이름이 `2026-03-18_수_1930_김민지_001.jpg` 형식이면 날짜와 사람을 이름에서 읽습니다. 다른 이름의 사진은 촬영 정보(EXIF)에서 날짜를 읽고, 사람은 "이름모름"으로 둡니다.

## GitHub Pages에 올리기
1. 이 폴더를 GitHub 저장소에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `/(root)`로 정합니다.
3. 잠시 뒤 `https://<계정>.github.io/<저장소>/` 주소가 생깁니다. 이 링크를 임원들에게 보냅니다.

앱 파일을 고친 뒤에는 `sw.js`의 `VERSION`을 올려야 폰에 저장된 옛 파일이 바뀝니다.

## 내 컴퓨터에서 시험하기
```
python3 -m http.server 8000
```
브라우저에서 `http://localhost:8000` 을 엽니다.

## 실제 기기에서 확인할 것
- [ ] 아이폰 사파리: 공유 → 홈 화면에 추가 → 아이콘으로 열기
- [ ] 안드로이드 크롬: ⋮ → 홈 화면에 추가 → 아이콘으로 열기
- [ ] 아이폰에서 "사진 고르기"로 불러올 때 위치가 남는지 (사진 선택 화면 **옵션 → 위치** 켜기)
- [ ] 아이폰 "파일에서 고르기 → 파일 선택"으로 고르면 위치가 남는지
- [ ] 안드로이드에서 "파일에서 고르기" → DCIM/Camera 폴더로 고르면 위치가 남는지
- [ ] 아이폰에서 ZIP 저장(파일 앱 → 다운로드)과 공유가 되는지, 홈 화면 앱에서도 되는지
- [ ] 아이폰·안드로이드에서 **보내기** → 카톡·메일(Gmail 등)이 목록에 나오고 ZIP이 가는지
- [ ] 카톡으로 받은 ZIP을 저장해서 **받은 파일 불러오기**로 열리는지 (아이폰은 "파일에 저장" 후)
- [ ] 홈 화면 앱을 껐다 켜도 모음함이 남아 있는지
- [ ] 사진 수백 장(수 GB)을 담을 때 폰 저장 공간 경고가 제대로 나오는지

도움말(`js/app.js`의 `HELP_HTML`)의 위치 살리는 방법은 위 항목을 기기에서 확인한 뒤 맞는 것만 남겨 주세요.
